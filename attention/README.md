# Attention

Mechanistic and pedagogical resources for **multi-head self-attention**: visualization tools, geometric analyses of BERT/transformer internals, toy-model factorizations, and minimal GPT training code for instrumentation.

PDFs are local (gitignored). Text extracts (`{citationkey}.txt`) are **local cache** when `bib.bib` records a public PDF or arXiv — regenerate with `../scripts/ensure-extract.sh {citationkey}`. Blog/HTML sources keep untracked `.txt` extracts at the permalink.
