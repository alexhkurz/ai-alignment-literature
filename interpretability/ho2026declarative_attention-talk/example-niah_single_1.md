# Example: RULER `niah_single_1` ("passkey")

What one test item of the paper's simplest task looks like. RULER does not ship fixed data: each item is generated by a script. The text below follows RULER's generator exactly (template, filler sentence, needle format); the key and the number are made-up values of the right kind, and the filler is abbreviated.

Source: RULER (Hsieh et al., 2024), task config `niah_single_1` in [`scripts/synthetic.yaml`](https://github.com/NVIDIA/RULER/blob/main/scripts/synthetic.yaml); generator [`scripts/data/synthetic/niah.py`](https://github.com/NVIDIA/RULER/blob/main/scripts/data/synthetic/niah.py); template in `constants.py`. In the DA paper this source averages 9.0K tokens of context (Table 1).

## The task definition

| Setting | Value | Meaning |
| :--- | :--- | :--- |
| `type_haystack` | `noise` | the filler is one sentence group, repeated |
| `type_needle_k` | `words` | the key is a random adjective–noun pair, e.g. `curious-lantern` |
| `type_needle_v` | `numbers` | the value is a random 7-digit number |
| `num_needle_k`, `num_needle_v`, `num_needle_q` | 1, 1, 1 | one needle, one value, one question |

## One item, as a plain (vanilla) prompt

```
Some special magic numbers are hidden within the following text. Make sure to memorize it. I will quiz you about the numbers afterwards.
The grass is green. The sky is blue. The sun is yellow. Here we go. There and back again.
The grass is green. The sky is blue. The sun is yellow. Here we go. There and back again.
The grass is green. The sky is blue. The sun is yellow. Here we go. There and back again.
[... the same line about 170 more times ...]
One of the special magic numbers for curious-lantern is: 6043197.
The grass is green. The sky is blue. The sun is yellow. Here we go. There and back again.
[... the same line about 230 more times ...]
What are all the special magic numbers for curious-lantern mentioned in the provided text?
```

Correct answer: **6043197**. The needle sits at a random line; about 400 repetitions of the filler give the ~9K tokens.

## The same item under Declarative Attention

The prompt side cuts the context into magic chunks of about 2,048 tokens, here about 5 chunks of ~90 filler lines each, delivered as `get_magic_chunk` tool results, followed by the question and the DA instruction (App. F). With the needle at line ~175, it falls into Magic Chunk 2.

The response the protocol asks for, following the instruction's "short factual / needle-in-haystack" shape (global → focus → local → answer). **This is what the protocol prescribes, not a recorded model output:**

```
<global>The question asks for the special magic number for curious-lantern.
The only line that is not filler is in Magic Chunk 2.</global>
<focus magic_chunks="2">"One of the special magic numbers for curious-lantern is: 6043197."</focus>
<local>The special magic number for curious-lantern is 6043197.</local>
<answer>6043197</answer>
```

What the engine does: during the `<focus>` passage the model reads the scaffold plus chunk 2, about 3K of the ~10K prompt tokens; during `<local>` only the scaffold and its own notes.

## What to take from it

- **Why accuracy is 100%** for both models, with and without DA (Table 2): the needle is the only line that differs from the filler. In global mode the model sees everything, so finding the chunk is trivial.
- **Why the saving is moderate**: Gemma reads 53% less, Qwen 18% less. The documents are short (~9K tokens), so the scaffold, about 1K tokens of instruction, is a large share of what focus and local still read, and the global step costs full price.
- **What it does not test**: anything about knowing where to look in a document with structure. It is the sanity check: if DA failed here, something would be broken.
- **Not specified in the paper**: how RULER's template is split into the DA prompt's question and context (e.g. where the line "Some special magic numbers are hidden…" goes).
