# Functional Data Analysis

**Authors:** James O. Ramsay, Bernard W. Silverman  
**Year:** 2005 (2nd ed.)  
**Venue:** Springer  
**Citation key:** `ramsay2005functional`  
**BibTeX entry:** [entry](../../bib.bib)  
**Google Scholar:** [Search](https://scholar.google.com/scholar?q=Ramsay+Silverman+Functional+Data+Analysis+2005)

## Summary

Standard textbook on functional data analysis: treats observations as smooth functions (curves, surfaces) rather than finite vectors, covering basis expansions, roughness penalties, registration, and functional linear models. HeRA cites it in connection with viewing layer-wise maps as functions over activation space when discussing regularity and approximation.

## Key concepts

- **Functional data** — data as functions of a continuous index.  
- **Basis expansions / smoothing** — represent functions in finite dimensions.  
- **Functional calculus viewpoint** — maps between function spaces.
