## Summary

Introduces Qwen2.5-VL, the flagship vision-language model of the Qwen series, with improved visual recognition, object localization, document parsing, and long-video comprehension. Key design choices include native dynamic-resolution ViT with window attention, absolute time encoding for temporal localization, and an interactive visual-agent mode for tool use and computer/phone control. The 72B model matches GPT-4o and Claude 3.5 Sonnet on document/diagram tasks; smaller 7B variants target edge AI.

## Key concepts

- **Native dynamic-resolution ViT** — processes images and videos at varying sizes without fixed normalization.  
- **Absolute time encoding** — second-level event localization in long videos.  
- **Visual agent capabilities** — reasoning, tool usage, and device control in real-world settings.  
- **Document/diagram understanding** — strong structured-data extraction from invoices, forms, charts, and layouts.
